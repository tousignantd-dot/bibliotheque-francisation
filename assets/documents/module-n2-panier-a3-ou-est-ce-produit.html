Séance A3 · Module 2 · 75 minutes

Où est ce produit ?

NomDate

Nommer ce qu'on voit dans un magasin, et savoir dans quel rayon chercher.

Objectifs

À la fin, je serai capable de…

  1. nommer les objets du magasin ;
  2. nommer les papiers des prix ;
  3. dire dans quel rayon se trouve un produit ;
  4. employer « c'est dans l'allée… ».
Vocabulaire · 1 de 2

Ce qu'on voit dans le magasin

un panierCe qu'on porte pour mettre ses achats dedans.
une alléeLe chemin entre deux rangées de tablettes.
une tabletteLa planche où les produits sont posés.
une caisseL'endroit où on paie, avant de sortir.
Vocabulaire · 2 de 2

Les trois papiers des prix

une circulaireLe grand papier qui montre les prix de la semaine.
une affichetteLe petit carton posé sur la tablette, sous le produit.
une étiquetteLe petit papier collé sur le produit lui-même.
un spécialUn prix plus bas, seulement pendant quelques jours.
Analyse

Chaque produit a son rayon

Le produitLe rayon
le laitles produits laitiers, au fond
les pommesles fruits et légumes, près de l'entrée
le savon à vaisselleles produits d'entretien, allée 7
le painla boulangerie, près des caisses
Dans presque toutes les épiceries, le lait est au fond et les fruits sont à l'entrée. Ce n'est pas un hasard.
C'est dans l'allée…

Le numéro d'allée est le repère le plus simple du magasin.

« Le savon est dans <b>l'allée 7</b>. » On peut le trouver sans savoir lire les panneaux : les numéros sont écrits gros, en hauteur. Pour demander : « <b>C'est dans quelle allée ?</b> »
