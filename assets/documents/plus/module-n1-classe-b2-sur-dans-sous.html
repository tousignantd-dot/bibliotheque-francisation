Séance B2 · Module 4 · 75 minutes

Sur, dans, sous

NomDate

Trois petits mots pour dire où est la chose. Deux se ressemblent beaucoup : la main le dit mieux que l'oreille.

Objectifs

À la fin, je serai capable de…

  1. dire où est un objet ;
  2. employer sur, dans et sous ;
  3. entendre la différence entre sur et sous ;
  4. comprendre une consigne qui dit où prendre la chose.
Dialogue

Où est mon stylo ?

Écoutez deux fois avant de lire.

BOPHA
Ivan, où est mon stylo ?
IVAN
Ton stylo ? Il est sur la table.
BOPHA
Non. Il n'est pas sur la table.
IVAN
Regarde sous la chaise.
BOPHA
Ah oui ! Il est sous la chaise.
Le petit mot passe devant

sur la table, dans le sac, sous la chaise.

En français, le petit mot vient toujours <b>avant</b> le nom. On ne dit jamais « la table sur ». L'ordre ne change pas.

Analyse

Trois places

Le motOù est la chose
surdessus, on la voit
dansà l'intérieur, cachée
sousen dessous, plus bas
Si vous devez ouvrir quelque chose pour la prendre, c'est « dans ».
Attention

Confondre sur et sous

On entend souvent

« Le sac est sur la chaise » — alors qu'il est dessous.

Il faut dire plutôt

La main en haut pour sur, en bas pour sous.

Ces deux mots ne diffèrent que par une voyelle, et l'erreur ne se voit pas à l'écrit. Le geste de la main, fait en parlant, la corrige tout seul.

Mini-leçon

Sur, dans, sous — dire où est la chose

Trois mots, trois places

Pour dire où est un objet, trois petits mots suffisent presque toujours en classe : sur (dessus), dans (à l'intérieur), sous (en dessous). Ils se placent avant le nom : sur la table, dans le sac, sous la chaise.

« Sur » et « sous » se ressemblent beaucoup à l'oreille. C'est la seule vraie difficulté des trois.

sur — dessus

L'objet touche le dessus.

On ditLe livre est sur la table.
On ditL'horloge est sur le mur.
On voit l'objetoui

On dit Le livre est sur la table.

On dit « sur le mur » pour ce qui est accroché : une horloge, une affiche, un calendrier.

dans — à l'intérieur

L'objet est caché à l'intérieur d'un autre.

On ditLe stylo est dans le sac.
On ditLes feuilles sont dans le livre.
On voit l'objetnon

On dit Le stylo est dans le sac.

Si vous devez ouvrir quelque chose pour le prendre, c'est « dans ».

sous — en dessous

L'objet est plus bas, caché par le dessus.

On ditLe sac est sous la chaise.
On ditLe stylo est tombé sous la table.
Se ressemble àsur

On dit Le sac est sous la chaise.

« Sur » et « sous » : écoutez la voyelle du milieu. Dans le doute, regardez en haut et en bas — l'objet vous le dira.

Trois erreurs qui reviennent

Le piège

confondre sur et sous

Ce qui arrive

« le sac est sur la chaise » alors qu'il est dessous

Ces deux mots ne diffèrent que par une voyelle. Faites le geste de la main en parlant : en haut pour « sur », en bas pour « sous ».

Le piège

mettre le petit mot après

Ce qui arrive

« la table sur »

En français, le petit mot passe toujours devant le nom : sur la table, dans le sac, sous la chaise.

Le piège

dire « dans la table »

Ce qui arrive

pour un livre posé dessus

« Dans » veut dire à l'intérieur. Un livre posé sur une table est sur la table ; un livre rangé dans un tiroir est dans le tiroir.

Voyons si c'est clair

Quatre petites questions.

  1. Le stylo est à l'intérieur du sac. On dit…
    • sur le sac
    • dans le sac
  2. Le sac est par terre, la chaise est au-dessus. On dit…
    • sous la chaise
    • sur la chaise
  3. Sur, dans et sous se mettent…
    • avant le nom
    • après le nom
  4. Une horloge accrochée au mur est…
    • sur le mur
    • dans le mur
Réponses 1. dans le sac — Dans le sac : il est caché à l'intérieur. · 2. sous la chaise — Sous la chaise. · 3. avant le nom — Sur la table, jamais « la table sur ». · 4. sur le mur — Sur le mur.
