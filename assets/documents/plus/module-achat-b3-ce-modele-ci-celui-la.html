Ce modèle-ci, celui-là

NomDate

Devant deux appareils presque identiques, il faut désigner l'un plutôt que l'autre. Le français a deux outils — et il ne faut pas les mélanger.

Objectifs

À la fin, je serai capable de…

  1. employer ce, cet, cette, ces devant un nom ;
  2. employer celui, celle, ceux, celles à la place d'un nom ;
  3. distinguer -ci et -là ;
  4. reprendre un nom par un autre pour ne pas se répéter.

Le test : le nom est-il écrit juste après ? Si oui, ce/cet/cette.
cet, devant une voyelle

« cet appareil », jamais « ce appareil ».

<b>cet</b> existe précisément pour éviter la rencontre de deux voyelles : cet appareil, cet écran, cet homme. Devant une consonne, c'est <b>ce</b> : ce modèle, ce magasin.

Jamais celui tout seul

-là, -ci, qui, que ou de : il faut toujours une suite.

« celui-là », « celui de gauche », « celui qui consomme le moins ». « Celui » seul ne veut rien dire. Dans le doute, employez <b>-là</b> : c'est toujours correct.

-ci et -là

Deux choses côte à côte

-ci désigne le plus proche

« Ce modèle-ci » : celui devant lequel on se tient.

-là désigne le plus éloigné

« Celui-là » : l'autre, plus loin dans le rayon.

À l'oral, -là l'emporte

Beaucoup de gens emploient « celui-là » pour les deux, en montrant du doigt. Ce n'est pas une faute, c'est l'usage courant.

Reprendre par un autre nom

« la laveuse » devient « l'appareil », « le modèle », « la machine ».

C'est ce que fait le vendeur pour ne pas répéter le même mot. <b>appareil</b> est général, <b>modèle</b> désigne une version précise, <b>machine</b> est familier. Les alterner allège beaucoup un texte.

Attention

Mélanger les deux outils

On entend souvent

Celui modèle est plus économe.

Il faut dire plutôt

Ce modèle est plus économe. / Celui-là est plus économe.

Soit le nom est là, et on emploie <b>ce</b>. Soit il disparaît, et on emploie <b>celui</b>. Jamais les deux ensemble — c'est comme dire « le il ».
Pratique · 1 de 2

Accompagner ou remplacer ?

Complétez.

  1. Quelle est la différence entre ___ modèle-ci et celui-là ?
  2. ___ appareil est plus économe que l'autre.
  3. ___ laveuse fait soixante-huit centimètres.
  4. ___ deux modèles se ressemblent beaucoup.
  5. Prenez ___ de gauche : il entre partout.
  6. ___ est trop large pour votre local.
Pratique · 2 de 2

Supprimez la répétition

Récrivez la deuxième phrase.

  1. Prenez la laveuse. La laveuse de gauche entre partout.
  2. Regardez ce modèle. Ce modèle consomme le moins.
  3. Les deux appareils se ressemblent. Les appareils ont la même garantie.
  4. J'aime cette laveuse. Cette laveuse est silencieuse.
Billet de sortie

Comparez deux appareils en cinq phrases, sans jamais répéter leur nom.

  • Employez ce/cet/cette une fois, celui/celle deux fois.
  • Reprenez au moins une fois par un autre nom : l'appareil, le modèle.

Deux appareils côte à côte

Devant deux modèles presque identiques, il faut pouvoir désigner l'un plutôt que l'autre — sans les toucher, sans répéter leur nom à chaque phrase. Le français a deux outils pour ça, et il ne faut pas les mélanger.

L'un accompagne le nom, l'autre le remplace. Toute la leçon tient là.

Reprendre autrement

Une troisième façon d'éviter la répétition : changer de nom. « La laveuse » devient « l'appareil », « le modèle », « la machine ». C'est ce que fait le vendeur du module, et c'est très naturel à l'écrit.

Trois mots pour la même chose : appareil (général), modèle (une version précise), machine (familier). Les alterner rend un texte beaucoup plus léger.
