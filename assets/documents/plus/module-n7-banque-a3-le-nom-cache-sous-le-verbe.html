Le nom caché sous le verbe

NomDate

Un relevé n'écrit pas « vous devez payer avant le douze ». Il écrit « échéance du paiement ». Retrouver le verbe sous le nom, c'est lire à la vitesse normale.

Objectifs

À la fin, je serai capable de…

  1. reconnaître un nom formé sur un verbe ;
  2. former un nom en -ment, en -tion et en -ance ;
  3. donner le genre d'un nom d'après son suffixe ;
  4. revenir au verbe pour comprendre une ligne de document.
Analyse

Trois suffixes, trois genres

SuffixeCe que ça donne
-mentmasculin : le remboursement, le placement
-tionféminin : une opération, une contestation
-anceféminin : l'échéance, l'assurance
aucunmasculin : un emprunt, un prêt, un retrait
Trois règles couvrent presque tout le vocabulaire financier.
Le suffixe donne le genre

-ment fait un nom masculin ; -tion et -ance font un nom féminin.

C'est une des rares règles de genre du français qui n'ait pas d'exception utile. Elle vaut bien au-delà de la banque : l'inscription, la réparation, le renseignement, le déménagement.

Attention

Le piège

On entend souvent

Il faut dire plutôt

la déduction, la contestation

Un suffixe ne se colle pas au hasard sur un verbe : chaque famille a son nom, et il s'apprend avec elle. Le bon réflexe n'est pas d'inventer mais de relever le nom dans le document, où il est déjà écrit.

Mini-leçon

Les noms que la finance fabrique

Pourquoi les documents écrivent des noms là où l'on dirait des verbes

Un relevé n'écrit pas « vous devez payer avant le douze » : il écrit « échéance du paiement : le douze ». Ce n'est pas de la coquetterie. Un nom permet de nommer l'action sans dire qui la fait, et de la faire tenir dans une colonne de tableau. Le lecteur qui sait retrouver le verbe sous le nom lit ces documents à la vitesse normale ; les autres les relisent trois fois.

Le programme du niveau 7 range ce point sous « formation des mots » : employer les préfixes et les suffixes dans la formation de mots, exploiter les familles de mots pour la nominalisation.

Le suffixe -ment : un nom masculin, tiré du verbe

C'est le plus fréquent des relevés et des contrats. Il nomme l'opération elle-même.

La sérierembourser → le remboursement · placer → le placement · verser → le versement
Deux de plusprélever → le prélèvement · rendre → le rendement
Le genremasculin, sans exception

On dit Le remboursement, le placement, le versement, le prélèvement, le rendement.

Attention à « rendement » : le nom n'a pas tout à fait le sens du verbe « rendre ». C'est ce que le placement rend, oui, mais dit en pourcentage.

Le suffixe -tion : l'action devient une chose

C'est le suffixe des démarches et des documents officiels.

La sérieopérer → une opération · contester → une contestation · cotiser → une cotisation
Deux de plusdéduire → une déduction · protéger → une protection
Le genreféminin, sans exception

On dit Une opération, une contestation, une cotisation, une déduction, une protection.

Certains sont irréguliers dans leur formation — « déduire » donne « déduction », pas « déduisation ». Ils s'apprennent par familles.

Le suffixe -ance ou -ence, et les noms sans suffixe

Une troisième famille, plus petite, et une quatrième qui n'obéit à rien.

En -ance / -enceéchoir → l'échéance · assurer → l'assurance · différer → la différence
Sans suffixeemprunter → un emprunt · prêter → un prêt · retirer → un retrait
Le genreféminin pour la première série, masculin pour la seconde

On dit L'échéance, l'assurance, la différence, un emprunt, un prêt, un retrait.

Les noms sans suffixe sont les plus courts et les plus fréquents : ce sont ceux qui apparaissent en tête de colonne dans les tableaux.

Quatre questions sur les suffixes ; répondez sans relire.

    • masculins

  3. « Échéance » vient du verbe…
    • échanger
    • échoir

    • le nom
    • le verbe
Réponses 1. masculins — Le remboursement, le placement, le versement : tous masculins. · 2. féminins — Une opération, une contestation, une cotisation : tous féminins. · 3. échoir — Échoir : arriver à son terme. Le verbe est rare, le nom est partout. · 4. le verbe — « Je conteste » se comprend mieux que « la contestation est déposée ».
