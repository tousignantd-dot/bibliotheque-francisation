Séance B2 · Module 9 · 75 minutes

Le code postal, et qui écrit à qui

NomDate

Lire et écrire un code postal, reconnaître les abréviations de l'adresse, et savoir où va son propre nom.

Objectifs

À la fin, je serai capable de…

  1. lire un code postal caractère par caractère ;
  2. reconnaître app., boul., av., ch., C.P. et QC ;
  3. distinguer l'expéditeur du destinataire ;
  4. placer chaque nom au bon endroit sur l'enveloppe.

Dialogue

Et vous, vous êtes qui ?

Écoutez, puis trouvez qui est qui.

LUC
Madame, il manque une chose.
AMARA
Ah bon ? Quoi ?
LUC
Votre nom et votre adresse.
AMARA
Mon adresse ? Pourquoi ?
LUC
Vous êtes l'expéditeur.
AMARA
Et mon frère ?
LUC
Lui, c'est le destinataire.
Deux personnes sur une enveloppe

En haut à gauche, celui qui envoie. Au milieu, celui qui reçoit.

L'<b>expéditeur</b> écrit son nom en haut, à gauche, en petit. Le <b>destinataire</b> va au milieu, en plus gros. Le timbre reste en haut, à droite. Si la personne a déménagé, la lettre revient chez l'expéditeur : c'est à cela que sert ce coin-là.

Écriture

Le code postal

Complétez avec un seul mot.

  1. Un code postal a ___ caractères.
  2. Le premier caractère est une ___.
  3. Le deuxième caractère est un ___.
  4. Le code postal s'écrit à la ___ de l'adresse.
  5. H1T 1C5 : cette adresse est à ___.
Compréhension

Vrai ou faux ?

Répondez d'après le dialogue.

  1. Il manque le nom d'Amara sur l'enveloppe.
  2. Amara est l'expéditeur.
  3. Son frère est l'expéditeur, lui aussi.
  4. L'adresse de l'expéditeur va en haut, à gauche.
  5. Le préposé dit d'écrire en gros.
