Le nom caché sous le verbe

NomDate

Un relevé n'écrit pas « vous devez payer avant le douze ». Il écrit « échéance du paiement ». Retrouver le verbe sous le nom, c'est lire à la vitesse normale.

Objectifs

À la fin, je serai capable de…

  1. reconnaître un nom formé sur un verbe ;
  2. former un nom en -ment, en -tion et en -ance ;
  3. donner le genre d'un nom d'après son suffixe ;
  4. revenir au verbe pour comprendre une ligne de document.
Analyse

Trois suffixes, trois genres

SuffixeCe que ça donne
-mentmasculin : le remboursement, le placement
-tionféminin : une opération, une contestation
-anceféminin : l'échéance, l'assurance
aucunmasculin : un emprunt, un prêt, un retrait
Trois règles couvrent presque tout le vocabulaire financier.
Le suffixe donne le genre

-ment fait un nom masculin ; -tion et -ance font un nom féminin.

C'est une des rares règles de genre du français qui n'ait pas d'exception utile. Elle vaut bien au-delà de la banque : l'inscription, la réparation, le renseignement, le déménagement.

Application

Complétez avec le nom de la même famille

Le verbe est entre parenthèses.

  1. Elle rembourse chaque mois : le ___ dure quatre-vingts versements.
  2. L'argent est placé pour deux ans : c'est un ___ à court terme.
  3. Une somme est retirée chaque mois : c'est un ___ automatique.
  4. Elle conteste le montant : sa ___ est ouverte le jour même.
  5. Elle cotise à son régime : sa ___ est déductible.
  6. Le paiement échoit le douze : l'___ est donc le douze.
  7. Elle emprunte douze mille dollars : son ___ dure six ans.
Attention

Le piège

On entend souvent

la déduisation, le contestement

Il faut dire plutôt

la déduction, la contestation

Un suffixe ne se colle pas au hasard sur un verbe : chaque famille a son nom, et il s'apprend avec elle. Le bon réflexe n'est pas d'inventer mais de relever le nom dans le document, où il est déjà écrit.
