Séance A3 · Module 8 · 75 minutes

Les seize mots du logement

NomDate

Quatre familles : les pièces, l'annonce, les gens, l'immeuble. Seize mots qui reviennent dans les seize séances.

Objectifs

À la fin, je serai capable de…

  1. nommer les pièces : le salon, la cuisine, la chambre, la salle de bain, le balcon ;
  2. nommer ce que dit une annonce : meublé, chauffé, l'électricité comprise ;
  3. nommer les personnes : le propriétaire, le locataire, le concierge ;
  4. nommer l'immeuble : le sous-sol, la buanderie, le stationnement.

Le mot et sa définition

Dites de quel mot il s'agit.

  1. L'argent qu'on donne chaque mois.
  2. La pièce fermée où on dort.
  3. Le papier qu'on signe pour douze mois.
  4. Un logement où les meubles sont déjà là.
  5. La personne à qui le logement appartient.
  6. La partie de l'immeuble sous le rez-de-chaussée.
