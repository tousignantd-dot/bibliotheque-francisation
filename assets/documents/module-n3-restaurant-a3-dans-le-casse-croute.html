Séance A3 · Module 4 · 75 minutes

Dans le casse-croûte

NomDate

Le comptoir, le plateau, les bacs d'ustensiles, les sachets de condiments : huit objets qu'on voit tous les midis et qu'on ne sait pas encore nommer.

Objectifs

À la fin, je serai capable de…

  1. nommer les huit objets d'un comptoir de casse-croûte ;
  2. décrire chaque objet en une phrase ;
  3. distinguer ce qu'on prend soi-même de ce qu'on demande ;
  4. employer chaque mot avec son article.

Les objets du comptoir

Quatre mots

un plateau

Le carré de plastique qui porte le repas. Il se prend au début du comptoir, avant même de commander, et se rapporte au bac à vaisselle en partant.

un ustensile

La fourchette, le couteau ou la cuillère. Au singulier, le mot est rare ; on dit presque toujours « les ustensiles », au pluriel.

une serviette de table

Le petit papier carré. Le mot complet est important : « une serviette » toute seule peut aussi vouloir dire celle de la salle de bain.

un condiment

Le sel, le poivre, le ketchup, la moutarde. Ce qu'on ajoute pour le goût, et qui vient en petits sachets.

Le mot complet, toujours

« une serviette de table »

Trois mots, jamais deux. Une serviette de bain, une serviette de plage et une serviette de table sont trois objets très différents. Au comptoir, le mot complet évite un malentendu qui fait sourire.

Vocabulaire

Quel objet ?

Nommez l'objet décrit.

  1. Le carré de plastique qui porte le repas.
  2. Le grand panneau au-dessus de la caisse.
  3. Ce qu'on prend dans les bacs pour manger.
  4. Le petit papier pour s'essuyer les mains.
  5. Le sel, le poivre, le ketchup.
  6. Le rond de plastique qui ferme un bol.
