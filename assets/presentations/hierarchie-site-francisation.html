Hiérarchie des pages du site

Les deux portes d'entrée du site, ce qui s'ouvre derrière elles, et les pages qu'on n'atteint que par leur adresse. Chaque bloc est cliquable et s'ouvre dans un nouvel onglet, sur le serveur choisi ci-dessus. Un code élève saisi dans la barre est ajouté aux liens qui en attendent un.

Entrée 1 — l'élève racine du site : / sert eleve.html

L'élève n'a ni compte ni mot de passe : il entre un code à six caractères que l'enseignante lui a remis. Tout ce qu'il voit dépend de la planification de son groupe, et le niveau du groupe borne ce qu'on peut lui ouvrir.

  • Portail élève/ → eleve.htmlEntrée
    Écran de code, puis le tableau de bord : bilan en trois chiffres, « Votre prochaine étape », modules du cours en tuiles, ateliers thématiques, exercices libres.
    • Entrer dans une séance/s/CODE → seance.html?c=…Sans compte
      L'autre porte du portail : l'élève scanne le code QR d'une feuille imprimée, reçoit un jeton anonyme gardé par son appareil, et ouvre le module — sans compte, sans pseudo, sans écrire son nom. Recharger la page retrouve le même participant.
    • Cadre d'ouverture d'une activitéviewer.html?src=…&code=…
      Barre de titre + iframe. Il passe le code élève à l'activité et remonte les traces de progression. Le lien ouvre le module 1 du niveau 4 en exemple.
      • Modules de coursassets/interactive/module-*/87 modules · 8 niveaux
        Cours de 4 h du matin, seize séances en quatre blocs. Chacun est un HTML autonome découpé en sections (Je découvre · Défis · Je me lance · Je retiens des mots). La couleur d'un module est celle de son niveau.

        • Rail « Mes outils »assets/design-system/outils-eleve.js7 outils
          Traduire · Lire · Simplifier · Prononcer · Demander à l'assistant · Mon carnet · Réviser. Greffé dans les modules, jamais écrit module par module — il n'a pas de page à lui. Un centre peut refuser l'assistant : les outils d'IA disparaissent alors, le module tient debout sans eux.
          • Cartes mémoire (vocabulaire)vocabulaire-flash/
            Ouvert par l'outil « Réviser » sur la liste du module. Répétition espacée à sept boîtes ; seule porte d'entrée dans la progression du vocabulaire.
        • Bouton de vitesse des voixassets/design-system/En-tête
          L'élève ralentit toutes les voix du module depuis l'en-tête. Greffé lui aussi, sur les modules et sur le gabarit.
      • Ateliers thématiquesassets/interactive/<slug>/27 ateliers
        Enquêtes, visites, jeux de rôle, mystères. Activités de 2 h de l'après-midi, par opposition aux modules du matin. Elles sont datées comme les modules.

Ce que l'élève ne voit jamais : le catalogue, la planification, les autres groupes, et les corrections IA de ses camarades. Le portail ne rend que les activités ouvertes à son groupe — et rien ne part vers l'enseignante sans un geste de dépôt de sa part.

Entrée 2 — l'enseignante page d'accueil du personnel : enseignant.html

Le portail enseignant porte sa propre connexion et remplace l'usage courant des anciennes pages. Plusieurs enseignantes, plusieurs groupes : le catalogue est commun, la planification se fait par groupe, et le niveau choisi à la création du groupe borne le catalogue et le matériel.

  • Portail enseignantenseignant.htmlEntrée
    Connexion, sélecteur de groupe, puis les vues dans une seule page. Session partagée avec les autres pages du personnel par localStorage.
    • Onglet · PlanifierDans la page
      Dater les activités du groupe. Le chevron déplie les sections d'un module, cochables et datables une à une.
    • Onglet · ÉlèvesDans la page
      Inscrire un élève sous un pseudo, générer son code à six caractères, renommer, retirer, imprimer les billets. Un élève ne s'inscrit jamais lui-même.
    • Onglet · Groupes et comptesDans la page
      Créer un groupe et son niveau, gérer les comptes enseignants, le mot de passe, le lien de rencontre et les fichiers partagés au groupe.
    • Vue · MatérielDans la page
      Dépôt des PowerPoints et des fiches à imprimer, avec promotion d'un dépôt vers l'officiel (réservé à l'admin).
      • Plans de coursassets/plans/12
        Le lien ouvre le plan de l'enquête criminelle, en exemple.
      • PowerPoints des séancesassets/powerpoints/1 238 séances · 86 modules
        Fichiers .pptx, un dossier par module — ils se téléchargent depuis la vue Matériel, pas depuis une page à eux.
    • Progression du groupeprogression.html
      Le tableau de bord du groupe, module par module : qui a fait quoi, où ça bloque. En tête, le direct de la classe — la réussite question par question, pendant la séance. Il suit aussi bien les élèves inscrits que les participants anonymes d'une séance sans compte, sous « Participant 7 ».
      • Fiche de l'élèvefiche-eleve.html?code=…
        Le dossier d'un seul élève : parcours, vocabulaire maîtrisé, productions orales et écrites déposées. Les corrections IA privées n'y apparaissent jamais.
      • Feuille d'une séancefeuille-seance.html?code=…À imprimer
        Ce qu'on photocopie pour une classe sans compte : le code QR, le code à six caractères en gros, et l'adresse écrite en toutes lettres. Format lettre, aucune couleur. Le carré est fabriqué par le serveur (qr.py), jamais par un service extérieur, et l'adresse vient de l'en-tête Host — un nom de domaine acheté plus tard n'oblige à rien changer. Elle s'ouvre depuis « Séance sans compte », dans le portail enseignant.
    • Cataloguecatalogue.html177 activités
      Le fonds, pas la planification : toutes les activités, tous niveaux confondus, et les sept emplacements de matériel qui vont avec. Deux gestes seulement — ajouter une activité, ajouter du matériel. Aucune date, aucune suppression.
    • Comptes du personnelprof.html
      Connexion, installation du premier compte, et les comptes enseignants — ouvrir, retirer, réinitialiser un mot de passe. Les groupes en sont partis : ils vivent dans le portail.
    • Compositeur d'activitéassets/outils/compositeur-activite.htmlAutonome
      Ni session, ni groupe : il assemble un prompt à partir des critères du programme. Sur le poste local, la forge le fait générer pour vrai.
    • Tutoriels de l'espace enseignantassets/outils/tutoriels-enseignant.htmlAutonome
      Les capsules vidéo (assets/tutoriels/*.mp4 et leurs sous-titres) : tour du portail, planifier, sections, élèves, matériel.
      • Guide de l'espace enseignantguide-espace-enseignant.html
    • Correcteur collaboratifHors dépôt
      Application distincte, déployée ailleurs et ouverte depuis la barre des sections. Son dépôt et son Railway sont séparés de celui-ci.

Entrée 3 — la direction le lien « Espace direction » ne paraît qu'à qui a la charge d'un centre

Gérer des comptes et regarder une dépense n'est pas enseigner : ces pages sont sorties du portail enseignant. C'est le serveur qui dit qui y entre (/api/direction/portees), jamais un rôle deviné dans la page. La portée se lit dans l'arbre des organisations — réseau, CSS, centre — et non dans le rôle du compte.

  • Espace directiondirection.htmlEntrée
    Une seule page, deux portées : une direction y voit son centre, le fondateur voit le réseau. Comptes du centre, usage, drapeau IA par personne, invitations.
    • Les chiffreschiffres.html3 vues
      Réseau, CSS, centre. Les tableaux lisent le relevé quotidien (data/stats_jour.json), jamais le journal d'événements : la vue d'un CSS ne porte aucun identifiant d'enseignant. Les minutes affichées sont un plancher, et les écrans le disent.
    • Console du réseaureseau.htmlFondateur
      C'est d'ici que tout se règle pour le réseau entier. L'arbre des organisations — réseau → CSS → centres → rattachements —, les accès, les invitations, et les quatre drapeaux qu'une direction pose sur n'importe quel nœud : l'aide de l'assistant, la reconnaissance vocale, le dépôt des enregistrements, et les classes sans compte élève. Chacun s'hérite en descendant l'arbre, et le premier réglage explicite tranche. Réservée au fondateur ; on y entre par prof.html ou direction.html.
      • Accepter une invitationbienvenue.html?jeton=…
        La page où un compte invité se crée son mot de passe. Sans jeton valable, elle ne dit rien d'autre que « cette invitation n'est plus valable ».
Le mode sans IA : une direction peut refuser l'assistant pour son centre, et le drapeau existe aussi sur un compte. Le plus précis gagne — la personne, puis les nœuds de l'arbre. Les modules se replient alors sans se casser.

Derrière les pages le serveur, en une ligne par famille

Un seul server.py (http.server, stdlib) sert les fichiers statiques et répond aux appels JSON. Les traces vivent en fichiers JSON ou dans Postgres selon l'environnement (db.py) ; aucune page n'a de base à elle.
