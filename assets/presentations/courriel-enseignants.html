Le courriel aux enseignants

Un modèle standard : on y colle le code de la personne et on envoie. Ce qui est EN AMBRE se remplace ; tout le reste se garde tel quel, d'un envoi à l'autre.

À savoir avant d'envoyer

Un compte s'ouvre avec deux éléments temporaires : un code de six caractères et un mot de passe de huit. Les deux sont remplacés obligatoirement à la première connexion — pas seulement le mot de passe, parce qu'un code qui a circulé n'est pas plus secret qu'un mot de passe qui a circulé.

Mais les deux dans le même courriel, c'est la porte du compte dans un seul message. Le modèle ci-dessous n'envoie donc que le code, et fait passer le mot de passe par un second canal — un appel, un message texte, une phrase dans le corridor. C'est trente secondes de plus et ça change la nature de ce qui traîne dans une boîte de réception. La variante tout-en-un est plus bas, avec ce qu'elle coûte.

Le modèle — recommandé

Objet : Votre accès à francis — PRÉNOM NOM

Bonjour PRÉNOM,

Votre accès à francis est ouvert. C'est la plateforme qu'on utilise cette session pour les cours de francisation : les modules du matin, le suivi des élèves et les productions orales et écrites s'y trouvent au même endroit.

Pour entrer :
portail.edufrancis.ca/enseignant.html
Votre code : XXXXXX
Votre mot de passe temporaire : je vous l'envoie par message texte (il ne voyage pas dans le même courriel que le code).

À la première connexion, la plateforme vous demande de choisir votre propre code et votre propre mot de passe. Ceux que je vous remets ne servent qu'une fois, pour entrer. Choisissez un code dont vous vous souviendrez : c'est celui que vous taperez tous les jours.

Ensuite, trois gestes et vous êtes en classe :

1. Ouvrez un groupe et choisissez son niveau — tout le reste s'ajuste à ce choix, à commencer par ce que vous verrez au catalogue.
2. Ajoutez vos élèves. On n'inscrit jamais leur vrai nom : chacun reçoit un pseudonyme, et c'est voulu.
3. Mettez un module à l'horaire du groupe. Les élèves y entrent avec leur propre code.

Comptez une quinzaine de minutes pour le tour du propriétaire. Si quelque chose ne se comporte pas comme vous l'attendez, écrivez-moi — c'est utile, et c'est souvent réglé le jour même.

La variante tout-en-un

Quand il n'y a pas de second canal — une personne que vous ne connaissez pas, sans numéro, à distance. Remplacez le bloc « Pour entrer » par celui-ci, et ajoutez la ligne de délai :

Votre code : XXXXXX
Votre mot de passe temporaire : XXXXXXXX

Ouvrez votre accès aujourd'hui si vous le pouvez. Ces deux éléments sont temporaires et cessent de servir dès que vous aurez choisi les vôtres — tant que ce n'est pas fait, ils traînent dans une boîte de réception.

Ce que cette variante coûte

Un courriel intercepté ou laissé ouvert sur un écran donne le compte entier, jusqu'à la première connexion de la personne. Le risque se ferme tout seul — mais seulement quand elle se connecte, et c'est pour ça que la phrase « aujourd'hui si vous le pouvez » n'est pas de la politesse. Si vous employez cette variante, notez de vérifier deux jours plus tard que le compte a bien été ouvert ; si ce n'est pas le cas, régénérez les accès plutôt que de relancer.

La relance, une semaine après

Objet : francis — votre accès est toujours ouvert

Bonjour PRÉNOM,

Je vois que votre accès n'a pas encore servi — aucune urgence, c'est seulement pour m'assurer que le courriel ne s'est pas perdu.

Si le code ne fonctionne plus ou si le message a disparu, dites-le-moi : je vous en fais un neuf en deux minutes. Et si vous préférez qu'on le fasse ensemble, quinze minutes devant l'écran suffisent largement.

Ce qui a été retenu, et pourquoi

  • Aucune pièce jointe. Comme pour le courriel aux directions : une pièce jointe fait hésiter, et fait parfois classer le message en indésirable.
  • Le code sur sa propre ligne, pas au milieu d'un paragraphe. Il sera recopié à la main, souvent depuis un téléphone.
  • L'alphabet du code exclut O, I, 0 et 1 — ils se confondent à l'oral et à l'œil. Inutile de l'expliquer dans le courriel, mais c'est pour ça qu'on peut dicter un code au téléphone sans épeler.
  • Le pseudonyme des élèves est dit dès le premier courriel. C'est la règle la plus contre-intuitive de la plateforme pour un enseignant : la découvrir en pleine saisie de groupe agace, la lire d'avance rassure.
  • On ne parle pas de l'assistance automatisée. Elle vient au bon moment, dans la plateforme. Un premier courriel qui l'annonce déplace la conversation avant que la personne ait vu quoi que ce soit.
  • On demande un retour, pas une évaluation. « Si quelque chose ne se comporte pas comme vous l'attendez » ouvre la porte sans réclamer un jugement.
